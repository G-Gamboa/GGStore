Estas views Razor (.cshtml) del proyecto original se usaron como referencia de UX:
- Producto/Index: panel de filtros (estado, talla, marca, genero, categoria, id)
- Producto/Vender: concepto de venta (aquí simplificado a 'Marcar vendido' sin datos de cliente/método)
- Dashboard/Index: KPIs (aquí versión simple + reservados)

En Next.js la UI es minimalista con Tailwind, pero conserva el flujo.
